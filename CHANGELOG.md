# Changelog

## 0.1.0

First release.

- Review a branch or your working tree against a base branch, including an agent's worktree and its uncommitted changes.
- Comment on lines, ranges, whole files, deleted lines, and the change as a whole. Threads stay attached as the code moves.
- Send the review to any coding agent by copying the path of the review file, and see replies appear in the overview and in the diff.
- Track which files you have viewed, and open just the changes made since then.
- Keep several reviews at once. A badge counts the threads waiting on you.
